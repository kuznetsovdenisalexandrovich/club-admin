# club-admin — дашборд клуба «Ты Боженька Продаж»

Панель управления для Denis'а: участники, оплаты, лекции, карточки, эфиры,
рассылки, доступы. Владелец — Denis, гуру продаж, **новичок в программировании**.
Отвечать по-русски.

## Что это

**Один файл `index.html` с CSS и JS внутри. Без сборки, не React.**
Вход по PIN. Все данные тянутся с бэкенда
`https://api.youselllikeagod-magazine.ru` (репозиторий `club-backend`,
приватный), админские ручки закрыты заголовком с токеном.

⚠️ **Мини-приложение участника — это ДРУГОЙ репозиторий `club-app`.** Оба зовут
главный файл `index.html`, их постоянно путают. Сверяться по содержимому:
PIN-экран и попапы → это админка; портал с вкладками → это апп.

⚠️ **У аппа и дашборда РАЗНЫЕ наборы классов и вспомогательных функций.**
Перенося сюда код из аппа, проверять каждый класс по таблице стилей ЭТОГО файла
и каждую вызванную функцию по объявлениям ЭТОГО файла. Уже ломалось.

## Метка сборки

`admin-vNNN` в имени выдаваемого файла **и в константе `BUILD_VERSION`** в
начале первого живого `<script>`. Оттуда номер сам подписывается внизу страницы
(`.build-mark` в конце `.shell`), так что выложенное опознаётся глазами.
**Поднимать оба места одним числом** — расхождение хуже отсутствия подписи.

⚠️ **Номер версии брать от выложенного, а не по памяти.** Уже выдавали v37 при
боевой v73, и скрипт выкладки молча отбросил файлы как устаревшие.

## ⚠️ Обязательные проверки перед коммитом

1. **Синтаксис — только на склейке ЖИВЫХ блоков**, отобранных регуляркой
   `<script(?![^>]*\bsrc=)[^>]*>`. Здесь подключён Chart.js внешним тегом, и
   около 10 КБ кода однажды легли ВНУТРЬ него — содержимое тега с `src`
   браузером игнорируется полностью, код просто никогда не исполнялся.
2. **Инвентарь функций до и после** — «пропавшие» должно быть пусто.
3. **Цели `onclick` существуют** — grep с якорем `^function имя(`.
4. **`jsArg(v)` обязателен** для любого значения внутри `onclick="..."`.
   `JSON.stringify` там даёт двойные кавычки, первая закрывает атрибут, и клик
   молча перестаёт работать. Проверка: вытащить `onclick="([^"]*)"` регуляркой и
   убедиться, что скобки сбалансированы.
5. **Классы из кода против таблицы стилей** и **вложенность CSS стеком**, а не
   счётом скобок.
6. **Имя хелпера сверять точно**: здесь `escapeHtmlText`, а не `escapeHtml`.
   Ошибка тонет в `catch`, консоль остаётся пустой.

## Грабли этого файла

- **Ловушка flexbox в строках списков.** У `<div style="flex:1">` с текстом
  внутри минимальный размер считается по содержимому — кнопки вылетают за край
  при длинном названии. В стилях уже есть общее правило
  `.pay-item > div[style*="flex:1"]{min-width:0}` и `flex-shrink:0` на кнопках;
  заводя новый список такого вида, проверить, что он под него попадает.
- **Картинки только через `stored_image_url` на бэкенде.** Часть артов лежит в
  закрытом хранилище ключом `s3:...`, часть старых — обычными адресами. Сырое
  поле даёт смесь рабочих и битых, и выглядит это как «тянет со старого
  сервера».
- **Убирая раздел, проверить, не проходил ли через него единственный путь к
  живому.** Снятая «Мастерская» за вечер убила три входа, хотя разметка и
  функции были целы.
- **Одно значение — одна ручка.** Уровень «Главных идей» правился из двух мест.
  Если смысл общий, вторая настройка ссылается на первую, а не хранит копию.
- **Проверять на том состоянии, в котором живёт заказчик.** Чинили загрузку арта
  на заполненном слоте, а у него все слоты пустые.

## Как работать с Denis'ом

- **Команды для терминала давать целиком, готовыми к вставке.** Не «поменяй
  строку» — он теряет пробелы и опечатывается.
- Он смотрит живьём и ловит то, чего не видно в коде. **Его описание симптома
  часто и есть диагноз**, скриншот стоит десяти гипотез.
- **«Правка не подействовала» — сначала проверить, выполняется ли код.** Две
  версии без эффекта = добывать факт с устройства, а не выдавать третью.
- **Эмодзи в интерфейсе — нет.** Эстетика: тёплый неоморфизм, матовое стекло.
- **Дизайн ведёт Denis.** Наша работа — замерить присланное и назвать блокеры.
- **Перед постройкой грепнуть файл**, даже будучи уверенным, что этого нет.
  Списки задач отстают на дни.
